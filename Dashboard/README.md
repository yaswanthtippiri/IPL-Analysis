# IPL Power BI Dashboard

This folder contains the original Power BI dashboard file.

## Dashboard Highlights
- IPL season selection.
- Champion and runner-up.
- Total sixes and fours.
- Total matches and teams.
- Centuries and half-centuries.
- Orange Cap and Purple Cap statistics.
- Points table.
- Highest fours and sixes.

## Tools
- Microsoft Power BI
- DAX
- Power Query
