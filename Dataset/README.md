# IPL Dataset

This folder contains the datasets used for IPL analysis from 2008 to 2025.

## Files
- `ball_by_ball_data.csv` – Ball-by-ball match information.
- `ipl_matches_data.csv` – IPL match details and results.
- `players-data-updated.csv` – Player information.
- `teams_data.csv` – IPL team information.

## Purpose
These datasets support match analysis, team performance analysis, player statistics, and season-wise insights.
