# IPL SQL Analysis

This folder contains SQL queries developed to analyze IPL data from 2008 to 2025.

## Analysis Areas
- IPL titles won by each team.
- Team-wise match wins.
- Player performance analysis.
- Orange Cap and Purple Cap analysis.
- Most runs, wickets, fours, and sixes.
- Season-wise match statistics.

## Tools
- SQL
- SQL Server Management Studio
